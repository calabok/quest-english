# Квест-Инглиш — прототип

Интерактивный прототип приложения для изучения английского через истории: 5 уровней (A1–C1), 60 сцен, тест уровня, Логово забытых слов, дуэли, бонусный мир «Фэнтези», озвучка и распознавание речи.

**Открыть:** https://calabok.github.io/quest-english/

Весь прототип — это один файл `index.html` без внешних зависимостей. Прогресс сохраняется в браузере (localStorage). Микрофон работает в Chrome, Edge и Safari по https.
